# Security & Abuse Prevention Policy

## Zero-Tolerance for Non-Consensual Voice Cloning
- This engine prohibits voice enrollment without active cryptographic consent validation.
- All synthesized audio includes an immutable provenance watermark proving it is AI-generated.
- Any attempt to bypass or strip consent gates violates the project's ethical guidelines.
